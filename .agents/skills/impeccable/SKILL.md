# Impeccable для Codex

Это проектный адаптер, зависит от общего workflow [Impeccable](../../../.claude/skills/impeccable/SKILL.md). Прочитай его целиком, затем выбранный playbook. Не копируй пакет и не запускай pin для создания Claude-команд.

- Корень пакета — `.claude/skills/impeccable`; cwd — корень проекта. В Windows запуск контекста: `.claude/skills/impeccable/scripts/impeccable.cmd context --target <файл>`. Загрузка может скачать бинарник; соблюдай разрешения среды. При сбое сообщи, что контекст не загрузился, и прочитай `PRODUCT.md`, `DESIGN.md`, применимый бриф напрямую, как предписано исходным workflow.
- Это Windows desktop Avalonia. `web` в PRODUCT.md — ограничение формата Impeccable, а не основание добавлять браузер, DOM/CSS или мобильные проверки. Для результата нужны headless-рендер Avalonia и существующий `HeadlessUi`; снимки сохраняй в `.impeccable/review/`.
- Перед UI-правками прочитай `reference/craft-floor.md` общего пакета. Сохраняй мир «каталог», токены и The Still Catalog Rule из DESIGN.md: мгновенные состояния, штатная обратная связь Fluent и разрешённый сдвиг полосы при переключении платформы (250 мс). Не превращай это правило в запрет уже утверждённого переключения.
- Read/Edit/Bash трактуй как доступные чтение / `apply_patch` / PowerShell. Подагенты `.claude/agents/impeccable-*.md` не запускаются автоматически: делегирование допустимо только при разрешении пользователя или действующих инструкций; при его отсутствии выполни необходимые проверки сам.
- Claude detector hooks не подключены к Codex. Не выдавай их наличие в пакете за исполняемую защиту. Проверяй bindings, жесты, состояния и визуальный результат средствами Avalonia.
- После правок — сборка и тесты по AGENTS.md, затем тематический коммит. Публикация и внешние сообщения не входят в дизайн-задачу.
