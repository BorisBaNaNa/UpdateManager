## 2.1.0.0

### Платформа Android

UpdateManager выпускает не только Windows. В проекте теперь две платформы, их включают в настройках: «Платформы → Windows / Android». Выпустить можно обе сразу или любую одну.

- **Android — без патчей**: Билд → **Подпись** → Доставка → Проверка. Сам apk собирается вне UpdateManager. Папка билда выбирается в строке «Папка Android».
- **Подпись файлов по маске**. Маски задаются в настройках, например `latest.json`, `*.apk`, `manifests/*.json`. Подпись делается RSA-ключом проекта — тем же, что подписывает патчи Windows: SHA-256, PKCS#1 v1.5, по сырым байтам файла. Рядом с файлом появляется `<файл>.sig` в base64. После подписи она сверяется с публичным ключом. Маска без совпадений — ошибка, а не тихий пропуск.
- **Версия** спрашивается при подписи. Из файлов UpdateManager её не читает. Если версия совпадает с Windows, получается один выпуск двух платформ.
- **Одна полоса на экране.** Под версией видна полоса выбранной платформы. Имена «Windows | Android» у версии — переключатель. Вторая полоса въезжает справа свайпом: перетаскиванием мышью или горизонтальной прокруткой тачпада. Главная кнопка всегда относится к видимой полосе.
- **Выкладка в канал** — папку `AndroidPatch` внутри папки патча (имя меняется в настройках). Выкладываются все файлы папки билда, кроме масок «Не выкладывать», и только «свои» `.sig`. Канал подменяется целиком: подписанный манифест и его подпись появляются на сервере одновременно с остальными файлами.
- **Защита от неподписанного обновления.** Если файл правили после подписи, выкладка откажет. Если билд изменился после подписи, в каталоге появится запись «новый».
- **Проверка канала** скачивает выложенное по публичному адресу и сверяет байты с папкой билда, а подписи — с публичным ключом.
- Повтор этапа сбрасывает следующие этапы, как у Windows.

### Доставка

- **Старое на сервере удаляется.** После успешной отправки в папке назначения остаётся ровно новая выкладка — и для FTP, и для доставки в папку. Раньше «чужие» файлы сохранялись — это был костыль под вручную выложенный AndroidPatch. Исключение — папка канала Android: доставка Windows её не трогает.
- Доставка в папку отказывается работать с корнем диска и с папкой, которая пересекается с источником.

### Что нового

- Окно **«Что нового»** один раз открывается само после обновления. Открыть его в любой момент — «Справка → Что нового…».
