## 2.3.0.0

### Версия Android из манифеста

- **Версию больше не нужно вводить при каждом выпуске Android.** В проекте только с Android UpdateManager ищет JSON-манифесты в папке сборки и её подпапках и читает строку `versionName`, например `"0.9.11"` из `latest.json`. Имя файла может быть любым; числовой `versionCode` не используется как номер выпуска.
- Найденная новая версия сразу появляется в каталоге и автоматически используется при подписи файлов или записи версии без подписи. Новый номер определяется даже при сохранённых старых датах файлов.
- Если подходящей версии нет или манифесты содержат разные версии, остаётся ручной ввод. При включённых Windows и Android сохраняется общая версия из Windows.

### Повторное сканирование сборок

- **Кнопка справа от «ВЫПУСКИ»** заново сканирует папки сборок Windows и Android. После пересборки нажмите её, чтобы обновить каталог без перезапуска программы и повторного выбора папки.
- Сканирование не меняет сохранённые выпуски и записи пройденных этапов. Для повторной подготовки той же версии используйте действие её этапа.
