## 2.4.0.0

### Инструкция подключения обновлений

- **Справка → Как подключить обновления…** — новое руководство для владельца приложения: подготовка клиента Windows или Android, настройка UpdateManager и проверка первого обновления A → B.
- Три этапа с раскрываемыми темами и переходами. Окно не блокирует работу: его можно держать рядом с настройками проекта.
- В разделе Windows — ссылки на Wiki SimplePatchTool, пример самообновления и репозитории движка и UpdateManager.
- **Документы** открывает папку с двумя методичками: инструкцией для пользователя и подробным заданием для агента-разработчика. Они поставляются вместе с приложением.

### О разработчике и проверка версии

- **Справка → О разработчике…** — версия приложения, ссылки на GitHub разработчика и исходный код UpdateManager, сведения о библиотеке SimplePatchTool и ссылки на её автора и репозиторий.
- Кнопка **Проверить обновления** перенесена из меню в это окно. Автоматическая проверка при запуске работает как прежде.

### Универсальные примеры

- Подсказки, инструкции и тестовые примеры обезличены: убраны названия, пути и настройки сторонних приложений-потребителей.
- Подсказка поля **Не выкладывать** теперь — `ignored_file.format`, пример FTP-хоста — `ftp.example.org`.
